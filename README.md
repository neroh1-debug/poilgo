# 성취평가와 추정분할의 이해 — 인터랙티브 발표

PDF 40장을 웹 슬라이드로 옮기고, 휴대폰 참여 기능을 붙인 발표 도구입니다.

## 실행

`시작.bat`을 더블클릭하거나, 이 폴더에서 다음 명령을 실행합니다(Node.js 18 이상).

```
npm install   (처음 한 번만)
npm start
```

| 화면 | 주소 |
|---|---|
| 발표 화면 (빔프로젝터) | `http://<노트북 IP>:8080/presenter`, 핀코드 **0821** |
| 참여자 (휴대폰) | 화면 오른쪽 아래 QR 스캔, 또는 `http://<노트북 IP>:8080/` |

서버가 시작되면 콘솔에 실제 접속 주소가 출력됩니다. 참여자 화면 오른쪽 위의 🔒 버튼으로도 핀코드를 입력해 발표자 모드에 들어갈 수 있습니다.

> **네트워크 주의**: 휴대폰이 노트북과 **같은 Wi-Fi**에 있어야 합니다. 학교 Wi-Fi가 기기 간 통신을 막는 경우(클라이언트 격리)에는 노트북을 휴대폰 핫스팟에 연결하거나, 아래 "외부 공개"를 사용하세요.

## 발표자 조작

| 키 | 동작 |
|---|---|
| → / Space / PageDown / Enter | 다음 슬라이드 (프레젠터 리모컨 사용 가능) |
| ← / PageUp | 이전 슬라이드 |
| 숫자 입력 후 Enter | 해당 페이지로 이동 (예: `2` `2` Enter) |
| F | 전체화면 |
| R | 현재 슬라이드 애니메이션 다시 재생 |
| Q | QR 카드 접기/펼치기 (클릭하면 크게 보기) |
| M | 질문 목록 열기/닫기 |

- **질문 확인** 버튼(왼쪽 아래)의 빨간 숫자는 아직 답하지 않은 질문 수입니다. 질문마다 *화면에 띄우기 / 답변 완료 / 삭제*를 할 수 있습니다.
- OX 슬라이드에서는 **O 또는 X 카드를 클릭하면 정답으로 표시**됩니다. 다시 클릭하면 해제됩니다.
- 하단 툴바의 **응답 초기화**는 현재 슬라이드의 응답만 지웁니다(리허설 후 사용).

## 인터랙션 페이지

| 페이지 | 참여자 입력 | 발표 화면 |
|---|---|---|
| 3 | 1~4 중 선택 (바꿀 수 있음) | 항목별 막대, 인원, 비율 |
| 4, 5 | 단어 입력 (1인 최대 5개) | 워드클라우드 (많이 나온 단어일수록 크게) |
| 22, 27, 31 | O / X 선택 (바꿀 수 있음) | O·X 카드 옆에 응답 수 뱃지 |
| 25 | 단어 입력 (1인 최대 3개) | 많이 나온 단어 TOP3를 01·02·03 카드에 채움, 오른쪽에 전체 순위 |
| 32 | 숫자 입력 (다시 보내면 바뀜) | 아래 빈칸에 응답 숫자를 하나씩 표시 |

참여자는 발표자가 현재 띄운 슬라이드만 볼 수 있고, 그 슬라이드가 인터랙션 페이지일 때만 입력할 수 있습니다. 띄어쓰기와 대소문자만 다른 단어는 같은 단어로 묶습니다(예: "성취 기준" = "성취기준").

## 외부 공개 (선택)

같은 Wi-Fi를 쓸 수 없으면 무료 터널로 외부 주소를 열 수 있습니다.

```
npx cloudflared tunnel --url http://localhost:8080
```

출력된 `https://….trycloudflare.com` 주소로 서버를 다시 시작하면 QR에 그 주소가 들어갑니다.

```
set PUBLIC_URL=https://….trycloudflare.com
npm start
```

Render, Railway 같은 Node 호스팅에 이 폴더를 그대로 올려도 동작합니다(`npm start`, 환경변수 `PIN`과 `PUBLIC_URL`은 선택).

## 파일 구성

- `server.js`: 실시간 서버 (Node 내장 http와 Server-Sent Events). 응답과 질문은 `state.json`에 저장되어 서버를 재시작해도 남습니다. **`state.json`을 지우면 전체가 초기화됩니다.**
- `public/slides.js`: 40장 슬라이드 내용과 애니메이션
- `public/app.js`: 발표자/참여자 화면 로직
- `public/img/`: PDF에서 추출한 이미지 (`tools/extract.py`로 다시 만들 수 있음)
